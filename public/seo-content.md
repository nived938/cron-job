## FAQ
### What is CronFlow?
CronFlow is a web platform for scheduling and monitoring recurring HTTP requests.
### Can I use custom cron expressions?
Yes. CronFlow supports standard cron expressions and timezone-aware schedules.
### Can I retry failed requests?
Yes. Jobs can be configured to retry after failures.
### Does CronFlow monitor uptime?
Yes. Uptime and HTTP monitoring can track availability and response performance.
### Are authenticated requests supported?
Yes. CronFlow supports request headers and protected secret variables.
